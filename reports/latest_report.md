## 5. 혼합 실험(39 run)에 미치는 영향

- 지금 설계는 "합성 적벽돌(B1) + 실제 **포장 중공블록** 팔레트"를 같은 클래스로 섞는다. 그래서 다음과 같은 일이 생긴다.
  - Real val과 Test189은 **실제 데이터와 같은 제품, 같은 현장**을 평가한다. 실제 비율이 높을수록 거의 당연히 좋아지므로, 비율 효과는 "그 제품에 대한 적응량"을 측정하게 된다.
  - **연구 대상(실제 적벽돌)에 대한 실제 평가 데이터가 없다.** 그래서 Q2–Q4(실제 비율이 연구 대상 성능을 올리는가, 최적 비율은 무엇인가)에 답할 수 없다.
  - 표현(HR / LR / CAD) 효과도 "적벽돌 자산 표현이 다른 제품의 실제 사진 전이에 주는 영향"이 된다. 해석은 가능하지만 연구 목적과 다르다.
  - 기존 M50 / Test189(0.985)도 같은 제품의 실제 데이터로 적응한 결과다. "적벽돌 실제 검증"이라고 표현하면 안 된다.
- **권고**
  1. **39개 혼합 실험을 보류한다.** 연구 대상 정의를 먼저 정한다.
     - (i) 연구 대상 = 적벽돌만: 실제 적벽돌 팔레트 이미지가 필요하다(새 촬영이나 공개 데이터, val / test용). Roboflow는 "다른 제품으로의 전이" 보조 평가로만 쓴다.
     - (ii) 연구 대상 = 팔레트 점토 조적재 전반(적벽돌 + 포장 블록): 클래스 정의를 넓혀 문서화하고, B1에 포장 블록 자산이 없다는 한계를 명시한 뒤 혼합 실험을 "제품 간 전이 + 적응" 실험으로 재정의한다.
